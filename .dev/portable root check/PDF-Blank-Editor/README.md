# 빈칸 작업실 · PDF Blank Editor

PDF 위에 **흰색 빈칸**을 그리고 테두리 색상·표시 여부와 텍스트를 설정한 다음, 전체 페이지를 JPEG로 변환하여 ZIP으로 저장하는 Windows용 로컬 웹 앱입니다. 편집 내용은 PDF와 별도의 파일로 보관할 수 있습니다.

## 실행

1. 배포 ZIP을 **모두 압축 해제**합니다.
2. `start.cmd`를 더블클릭합니다. 별도의 빌드·설치·관리자 권한은 필요하지 않습니다.
3. 기본 브라우저에서 `http://127.0.0.1:8765/`가 열립니다. 최신 Edge 또는 Chrome을 사용하세요.
4. 실행 중에는 콘솔 창을 열어 두세요. 종료하려면 브라우저 탭과 콘솔 창을 닫으세요.

Python, Node.js, npm은 **사용자 실행에 필요하지 않습니다**. Windows PowerShell 5.1과 .NET 기본 기능으로 동작합니다. 조직 정책이 PowerShell 실행을 금지한 PC에서는 정책 관리자에게 확인해야 합니다.

이미 실행 중이라는 안내가 나오면 기존 실행 창을 닫으세요. 다른 프로그램이 포트를 사용 중이라면 PowerShell에서 다음과 같이 실행할 수 있습니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\server.ps1 -Port 8766
```

`index.html`을 직접 더블클릭하지 말고 `start.cmd`를 사용하세요.

## 사용법

- **PDF 열기**: 파일을 선택합니다. 암호가 있으면 입력 창이 표시됩니다.
- **빈칸 그리기**: 페이지 위에서 마우스를 드래그합니다. 페이지마다 여러 개를 만들 수 있습니다.
- **선택 / 이동**: 빈칸을 클릭한 뒤 드래그합니다. 모서리의 작은 손잡이를 끌면 크기가 바뀝니다.
- **테두리·텍스트**: 선택한 빈칸의 오른쪽 속성 패널에서 테두리 표시 여부, 색상, 텍스트, 글자 크기를 바꿉니다. 새로 그린 빈칸은 바로 선택됩니다. 선택이 없을 때의 테두리·크기 설정은 앞으로 그릴 빈칸에 적용됩니다.
- **텍스트 입력**: 한글과 여러 줄 입력을 지원합니다. 검은색 가운데 정렬이며 상자에 맞춰 줄바꿈·축소됩니다. 텍스트는 빈칸마다 2,000자까지 입력할 수 있습니다. 작은 상자에 긴 내용을 넣으면 글자가 매우 작아지므로 상자를 넓혀 주세요.
- **삭제**: 선택 후 삭제 버튼 또는 Delete 키를 누릅니다.
- **실행 취소 / 다시 실행**: 버튼 또는 Ctrl+Z / Ctrl+Y를 사용합니다. 이력은 페이지별로 보관됩니다.
- **페이지 이동·확대**: 상단 화살표, 페이지 번호 입력, 확대·축소, 너비 맞춤을 사용합니다.
- **전체 JPEG 저장**: 150 / 200 / 300 DPI 상당의 출력 픽셀 크기를 선택하고 저장합니다. 모든 페이지를 ZIP 하나로 내려받습니다.
- **취소**: 변환 중 취소 버튼을 누르면 편집으로 돌아갑니다.

결과 파일은 `원본이름-빈칸-JPEG.zip`이고, 내부에는 `page-001.jpg`, `page-002.jpg` 등이 들어 있습니다. 빈칸이 없는 페이지도 포함됩니다. JPEG 품질은 95%이며 흰색 빈칸, 설정한 테두리, 입력한 텍스트가 이미지 픽셀에 합성됩니다. 원본 PDF는 수정되지 않습니다.

## 편집 내용을 저장하고 이어서 작업하기

1. **편집 저장**을 누르면 `원본이름.blank.json` 파일이 다운로드됩니다.
2. 원본 PDF와 이 편집 파일을 함께 보관합니다. PDF 안에는 편집 내용을 기록하지 않습니다.
3. 나중에 앱에서 **원본 PDF를 먼저 열고**, **편집 불러오기**로 `.blank.json` 파일을 선택합니다.
4. 모든 페이지의 빈칸 위치·크기·테두리·텍스트가 복원됩니다. 이어서 수정한 뒤 다시 편집 저장하세요.

편집 파일은 PDF 원본이나 암호를 포함하지 않습니다. 사용자가 입력한 텍스트, 빈칸 좌표, 원본 파일명과 대조용 SHA-256은 포함됩니다. PDF 이름은 바뀌어도 되지만 **파일 내용이 동일해야** 불러올 수 있습니다. PDF 자체를 수정하거나 다시 저장한 파일은 다른 문서로 판단할 수 있습니다.

JSON 저장은 편집 상태의 스냅샷입니다. 실행 취소 이력, 현재 확대율과 페이지 위치는 저장하지 않습니다. 불러올 때 형식·좌표·원본 일치를 검사하며, 오류가 나면 기존 편집을 유지합니다. 편집 파일 한 개는 최대 10MB, 빈칸은 최대 10,000개까지 지원합니다.

## 개인정보와 네트워크

- PDF 원본·암호·빈칸 좌표·변환 이미지를 외부 서버에 보내지 않습니다.
- PDF 파일은 브라우저 메모리에서 직접 읽습니다. 로컬 서버에도 PDF를 업로드하지 않습니다.
- 서버는 `127.0.0.1`에만 바인딩하며 앱의 정적 파일만 제공합니다. 업로드 API가 없고 GET/HEAD 외 요청을 거부합니다.
- PDF.js, 문자 매핑, 폰트, WASM, ZIP 라이브러리를 함께 배포합니다. 실행 중 외부 CDN이나 분석 서비스에 연결하지 않습니다.
- 외부 리소스를 제한하는 Content Security Policy를 적용했습니다. 문서에 포함된 링크와 스크립트를 실행하지 않습니다.
- 파일과 편집 내용은 앱이 디스크에 자동 저장하지 않습니다. 결과 ZIP과 편집 JSON은 사용자의 브라우저 다운로드 위치에 저장됩니다.
- 브라우저 확장 프로그램, OS, 다운로드 폴더의 클라우드 동기화 등 앱 밖의 동작은 별도입니다. 민감한 자료는 동기화되지 않는 로컬 폴더에 저장하세요.

## 알아두기

- 자동 저장은 없습니다. **창을 닫기 전에 ‘편집 저장’을 눌러 주세요.** JPEG 저장만으로는 편집 상태가 저장되지 않습니다. 미저장 경고는 편집 JSON 저장/불러오기를 기준으로 표시됩니다.
- 출력 해상도는 픽셀 수 기준입니다. JPEG의 DPI 메타데이터는 브라우저가 정하므로 인쇄 시 실제 용지 크기를 지정하세요.
- 페이지를 하나씩 변환하지만 ZIP 이미지들은 메모리에 모입니다. 512MB를 넘는 결과나 한 페이지 4천만 픽셀 이상은 안내 후 중단합니다. 큰 문서는 150 DPI를 선택하거나 PDF를 나누어 사용하세요.
- 일부 특수 PDF/XFA 문서는 지원되지 않거나 전용 PDF 뷰어와 다르게 보일 수 있습니다. 첫 출력의 글꼴·레이아웃을 확인하세요.

## 개발 및 검증

시작 페이지는 루트의 `index.html`, 앱 코드·스타일·라이브러리는 `web/`, 로컬 서버는 `server.ps1`입니다. 번들러나 빌드 단계가 없습니다. 테스트 도구만 개발용 Node.js가 필요합니다.

```powershell
npm ci --prefix .dev --ignore-scripts
node --test tests/*.test.mjs
```

테스트는 설치된 Edge를 사용하여 PDF 편집, JPEG 픽셀, 색상·테두리 없음·한글 텍스트, 프로젝트 저장·복원 및 잘못된 파일 거부, 회전/다른 크기의 페이지, 암호 PDF, 실패 복구, 취소, 네트워크 요청, 서버의 접근 제한을 검사합니다. 테스트용 PDF는 개발 도구로 생성합니다.

타사 라이선스는 `web/vendor/NOTICE.txt`와 각 LICENSE 파일을 확인하세요. `vendor-sha256.txt`에 배포 라이브러리 해시가 있습니다.
