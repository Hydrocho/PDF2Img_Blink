# 빈칸 스타일·텍스트·편집 파일

사용자가 요청한 기존 앱 확장이다. 빌드 없는 로컬 처리와 외부 전송 금지 요구를 유지한다.

## 동작
- 빈칸별 검은색 기본 테두리의 색상과 표시 여부를 변경한다. 채움은 흰색을 유지한다.
- 선택한 빈칸에 여러 줄의 일반 텍스트를 입력한다. 한글 지원, 기본 검은색/가운데 정렬, 글자 크기 선택, 자동 줄바꿈과 필요한 경우 축소로 상자 안에 맞춘다. HTML은 실행하지 않는다.
- 선택이 없으면 스타일 설정은 새 빈칸의 기본값이다. 새 빈칸 텍스트는 비워 둔다. 선택한 빈칸의 변경은 즉시 반영되고 실행 취소된다. 이동과 크기 변경에도 속성이 유지된다.
- 미리보기와 JPEG는 같은 그리기 함수를 사용한다.
- 편집 저장은 원본 PDF와 별개의 .blank.json 다운로드다. 원본 PDF와 암호를 포함하지 않고 빈칸 좌표, 테두리, 텍스트, 폰트 크기, 원본 파일명/페이지 수/SHA-256을 포함한다.
- 원본 PDF를 연 다음 편집 파일을 불러온다. 파일명 변경은 허용하며 바이트가 다른 PDF는 거부한다. 형식·크기·좌표·속성을 검증하고 오류 시 기존 편집을 보존한다.
- 불러오기는 모든 검증이 끝난 뒤 원자적으로 적용한다. 기존 미저장 편집이 있으면 덮어쓰기 확인한다. 불러온 뒤 이력은 새로 시작한다.
- 미저장 경고는 편집 JSON 저장/불러오기 기준이다. JPEG 출력은 편집 파일 저장을 대체하지 않는다.

## 접근 방식과 선택 근거
사용자가 PDF와 별도 저장을 요청했으므로 JSON sidecar를 사용한다. PDF 포함 프로젝트는 요구와 맞지 않고 크기가 커 제외한다. 브라우저 자동 저장만 하는 방식은 다른 PC로 옮기기 어려워 제외한다. 추가 승인 없이 요청된 변경 범위 안에서 구현한다.

## 검증
색/테두리 없음/한글 텍스트의 preview 및 JPEG 픽셀, 속성 변경 취소, 이동/리사이즈 속성 유지, 여러 페이지 저장·다시 열기, 다른 PDF 및 잘못된 JSON/좌표 거부, 취소 시 보존, 미저장 경고를 확인한다. 기존 테스트와 배포 ZIP smoke test도 유지한다.
