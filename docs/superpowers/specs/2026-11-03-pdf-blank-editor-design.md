# PDF 빈칸 편집기 설계

## 목적과 승인된 방향
Windows에서 PDF를 열고 각 페이지에 검은 테두리와 흰색 채움의 사각형을 여러 개 배치한다. 모든 페이지를 사각형이 합성된 JPEG로 내보낸다. 사용자는 인터넷 연결 여부보다 PDF가 외부로 전송되지 않는 것을 요구했다. 빌드 없는 HTML·JavaScript와 로컬 실행기 구성을 선택했다.

## 접근 방식 비교
- HTML 파일 직접 열기: 배포가 간단하지만 모듈·워커의 file URL 제약 때문에 제외한다.
- HTML·JavaScript와 로컬 실행기: 브라우저 기능을 활용하면서 빌드 없이 실행할 수 있다. 사용자가 선택한 방식이다.
- Windows EXE: 독립 창과 설치 프로그램을 제공할 수 있지만 패키징이 필요하므로 첫 버전에서는 제외한다.

## 실행과 개인정보 보호
- 제작자 제안: Windows PowerShell과 .NET 기본 기능을 사용하는 로컬 정적 파일 서버 및 시작.cmd를 제공한다. Python, Node.js, npm 설치를 요구하지 않는다.
- 서버는 127.0.0.1에만 바인딩한다. 자동으로 브라우저를 열고 콘솔 종료로 서버를 종료한다. 포트 충돌은 명확하게 알린다.
- 정적 앱 파일만 제공하며 GET/HEAD 외 요청과 경로 순회를 차단한다. PDF 업로드 API를 만들지 않는다.
- PDF는 사용자가 선택한 File의 바이트를 브라우저에서 읽어 PDF.js에 전달한다. 원본을 서버에 보내거나 자동 저장하지 않는다.
- PDF.js, 워커, 필요한 폰트·문자 매핑 및 ZIP 라이브러리를 로컬에 포함한다. 외부 CDN, 폰트, 분석, 원격 오류 수집 기능을 사용하지 않는다.
- CSP로 외부 연결과 외부 리소스 로드를 제한한다. PDF에 포함된 링크·스크립트 실행 기능을 제공하지 않는다.
- 외부 전송 방지는 앱 자체의 동작 범위이다. OS, 브라우저 확장 프로그램 등 앱 밖의 환경까지 통제하는 제품은 아니다.

## 편집 화면과 동작
- 한국어 UI. 상단에 PDF 열기, 페이지 이동, 확대/축소, 실행 취소/다시 실행, 전체 JPEG 저장 버튼을 둔다.
- 첫 버전은 PDF 한 개를 편집한다. 빈 화면에 사용 방법과 파일 열기 버튼을 표시한다.
- 현재 페이지에서 드래그하면 흰색 불투명 채움과 검은색 테두리의 사각형을 만든다. 페이지마다 사각형 수를 제한하지 않는다.
- 그리기/선택 모드를 명확하게 구분한다. 선택한 사각형은 이동, 모서리 핸들 크기 변경, Delete 삭제를 지원한다.
- 편집 좌표는 표시 배율과 무관한 페이지 좌표로 보관한다. 페이지 밖으로 사각형이 벗어나지 않게 한다.
- 페이지를 바꾸거나 확대해도 편집 내용이 유지된다. 페이지별 변경 이력으로 실행 취소/다시 실행을 제공한다.
- 새 PDF를 열 때 기존 편집 내용이 있으면 버리기 확인을 한다. 닫기/새로고침 시 미저장 편집 경고를 제공한다.
- PDF 렌더링 경합을 방지하여 빠르게 페이지를 바꿔도 이전 페이지가 덮어쓰지 않는다.

## 출력
- 제작자 제안: 해상도 150/200/300 DPI 상당의 픽셀 크기를 선택하며 기본 200, JPEG 품질 기본 0.95로 한다. DPI 메타데이터 설정을 보장하는 기능은 아니다.
- PDF 페이지를 흰 배경의 출력 캔버스에 렌더링한 후 같은 좌표계로 사각형을 합성한다. 선택 테두리와 핸들은 출력하지 않는다.
- 사각형이 없는 페이지도 포함해 모든 페이지를 순서대로 처리한다. 원본 PDF는 변경하지 않는다.
- page-001.jpg 형태의 파일들을 원본 파일명 기반 ZIP으로 다운로드한다. 페이지 수에 맞추어 자리수를 늘린다.
- 진행률과 취소 버튼을 제공한다. 내보내는 동안 편집은 잠근다. 완료·실패·취소 시 잠금과 임시 자원을 해제한다.
- 렌더링은 한 페이지씩 하며 캔버스를 재사용/해제한다. ZIP에 JPEG 데이터가 누적되는 메모리 한계는 남는다. 너무 큰 페이지와 메모리 오류는 안내하며 결과 성공으로 표시하지 않는다.

## 오류와 범위
- 잘못된 파일, 손상 PDF, 암호 필요 PDF, 렌더링 오류를 한국어로 안내한다. 암호 PDF는 암호 입력을 제공하며 암호를 저장하지 않는다.
- 자동 빈칸 탐지, OCR, 원본 PDF 편집/저장, 프로젝트 저장/불러오기, 여러 PDF 병합, Windows 설치형 패키징은 첫 버전 범위에서 제외한다.
- 첫 버전 목표 환경은 Windows의 최신 Edge/Chrome이다.

## 검증 기준
- 서로 다른 크기와 회전 방향의 페이지에서 여러 사각형을 만들고 이동·크기 변경·삭제·실행 취소가 정확하게 동작한다.
- 확대 및 페이지 이동 후에도 사각형 위치와 크기가 유지된다.
- 내보낸 ZIP의 JPEG 개수가 원본 페이지 수와 같고, 모든 사각형이 편집 화면과 같은 위치에 합성된다. 빈칸 없는 페이지도 보존된다.
- 네트워크 요청을 점검해 앱 리소스는 루프백 주소만 사용하며 PDF 바이트를 보내는 요청이 없음을 확인한다. 인터넷을 차단한 상태에서도 실행한다.
- 새 파일 열기, 암호 오류, 내보내기 취소, 빠른 페이지 전환에서 상태가 복구되는지 확인한다.
- 실행기와 정적 서버는 실제 Windows에서 시작·종료, 잘못된 경로 요청, 비허용 메서드 거부를 확인한다.

## 구현자에게 맡기는 사항
레이아웃 세부, 라이브러리의 검증된 버전 선택, 서버 구현 세부, 포트 번호, 테스트 도구는 구현자가 결정한다. 외부 전송 금지와 무빌드 실행 요구는 변경하지 않는다.
